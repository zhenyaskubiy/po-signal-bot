# Signal Bot | Pocket Option (OTC)

Сигнальний помічник для Pocket Option, який аналізує ринок у реальному часі
та надсилає торгові сигнали в Telegram. **Бот не відкриває угоди
автоматично** — рішення про вхід завжди залишається за користувачем.

## Що робить бот

- Аналізує OTC-інструменти Pocket Option: валютні пари, акції, криптовалюти, індекси (~50 інструментів, список редагується без зміни коду)
- Працює на таймфреймі **M1** (1 хвилина)
- Використовує індикатор **Supertrend** (ATR + Multiplier, налаштовувані)
- Визначає антитрендові свічки відносно напрямку Supertrend і рахує їх серію за заданими правилами (перші дві "якісні", далі — будь-якого розміру)
- Надсилає **попередження** (🟡) після 4-ї антитрендової свічки
- Через налаштований час (10-50 с) перевіряє 5-ту свічку і надсилає **основний сигнал** (🟢 CALL / 🔴 PUT)
- Аналізує лише інструменти з виплатою не нижче мінімальної (за замовчуванням 89%)
- Захищений від дублікатів — одне попередження й одне підтвердження на ситуацію
- Працює 24/7

## Статус проєкту

## Структура проєкту
po-signal-bot/
├── config/           налаштування (settings.yaml) + завантаження/перевірка
├── core/             Supertrend, підрахунок свічок, черга сигналів
├── data/             джерело котирувань (симулятор → потім реальне підключення)
├── notify/           Telegram: підписники, розсилка
├── tests/            тести логіки
├── logs/             логи роботи
├── main.py           точка входу
└── requirements.txt  залежності проєкту

⚠️ **Реальний токен і chat_id не комітяться в git**

## Встановлення й запуск

```bash
pip install -r requirements.txt
python main.py
```
